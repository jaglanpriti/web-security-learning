3. What is Burp Suite?

Burp Suite is a web application security testing platform used to inspect and analyze HTTP and HTTPS traffic.

4. Features I Am Learning

Proxy

Understanding and inspecting HTTP requests and responses.

HTTP History

Reviewing web traffic generated by the browser.

Repeater

Understanding how requests can be manually examined in an authorized lab.

Intruder

Learning automated request testing concepts in controlled environments.

5. Learning Objectives

- Improve web security testing skills.
