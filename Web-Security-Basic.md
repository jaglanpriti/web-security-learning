3. Core Concepts

HTTP Request

An HTTP request is a message sent by a client (browser) to a web server.

HTTP Response

An HTTP response is the message returned by the server to the client.

HTTP Methods

- GET – Retrieve information.
- POST – Submit information.
- PUT – Update resources.
- DELETE – Remove resources.

HTTP Status Codes

- 200 – OK
- 301 – Redirect
- 400 – Bad Request
- 403 – Forbidden
- 404 – Not Found
- 500 – Internal Server Error
